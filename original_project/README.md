# Original project (kept for reference)

These are the artifacts from the first pass at this project: the two coursework
report PDFs, the original `extract_judgments.py` extraction script, the two
exploratory notebooks (`eda.ipynb`, `analysis.ipynb`), and the cleaned CSV that
first pass produced (`cleaned_out.csv`).

They're kept here unmodified, for provenance — so the difference between this
version and the original is checkable rather than asserted. See the top-level
`README.md` and `reports/data_quality_report.md` for what changed and why.

The extraction script's raw output (`out.csv` there) lives at
`data/raw/out_raw.csv` in this repo — the input to the rebuilt pipeline in
`src/clean_data.py`.
